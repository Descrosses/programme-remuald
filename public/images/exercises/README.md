# Fiches techniques des exercices

Déposer ici une image par exercice, au nom indiqué par `techniqueImage` dans
`src/data/exercises.ts` (ex. `goblet-squat.webp`).

- Formats acceptés : `.webp` (recommandé), `.jpg`, `.jpeg`, `.png`. Seul le nom
  compte : `goblet-squat.png` est reconnu comme `goblet-squat.webp`.
- Le bouton « Voir le mouvement » apparaît tout seul au déploiement suivant,
  dès que le fichier est là. Aucune autre modification n'est nécessaire.
- Une fiche absente ne montre rien : pas de bouton, pas d'image cassée.
